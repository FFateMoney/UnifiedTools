# 目录规范

## 根目录规则

项目根目录下**只允许放文件夹**,不允许直接放普通文件。

唯一例外是"必要结构性文件",即工具或工程结构强制要求放在根目录的文件。当前允许的清单如下,新增必须先在本文档登记:

| 文件 | 原因 |
|---|---|
| `.gitignore` | git 要求放在仓库根目录 |
| `LICENSE` | 开源许可证,GitHub 只在根目录识别 |
| `README.md` | 仓库首页说明,GitHub 只在根目录显示 |

其他文件(说明、脚本、配置、草稿、临时输出)一律放进对应的文件夹。拿不准归哪一类时,先在本文档补充分类,再放文件。

## 顶层文件夹

| 文件夹 | 用途 |
|---|---|
| `doc/` | 所有文档:设计、规范、环境配置、决策记录 |
| `app/` | 应用源码(Xcode 工程及 Swift 代码) |
| `script/` | 构建、签名、打包等辅助脚本,需要时创建 |

新增顶层文件夹前先在本表登记。

## doc/ 内部分类

`doc/` 同样不放散文件,按类别建子文件夹:

| 子文件夹 | 内容 |
|---|---|
| `doc/conventions/` | 规范和约定(本文档所在处) |
| `doc/design/` | 方案和架构设计 |
| `doc/setup/` | 本机环境、签名、权限等配置说明 |

`doc/index.md` 是文档总目录,新增文档时在其中登记一行。
