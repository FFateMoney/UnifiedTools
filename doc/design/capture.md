# 截图(Capture)

对应里程碑 M4(基础版)。代码在 `app/UnifiedTools/Modules/Capture/`。

## 行为

默认快捷键 `⌃⌥A`(可在设置里改),菜单栏里也有"截图"入口。默认没用 `⌘⇧A`,因为它常被 macOS 自带的截图快捷键占用。

1. 按快捷键后,所有屏幕被定格成一张静止画面并压暗
2. 按住鼠标拖出选区,选区内保持原亮度,左上角显示像素尺寸;可以重新拖拽重选
3. 松开鼠标后,选区下方出现工具条:

| 按钮 | 作用 |
|---|---|
| 复制 | 图片放进剪贴板(回车等同于它) |
| 保存 | 存为 PNG 到 `~/Pictures/UnifiedTools/`,文件名 `Capture_日期_时间.png` |
| 贴图 | 选区变成置顶悬浮窗,保持在原来的位置 |
| 文字 | 识别选区里的文字,结果放进剪贴板,并弹出可编辑的结果窗口 |
| 取消 | 退出(`Esc` 等同于它) |

在截图界面再按一次 截图快捷键 也会取消。

贴图窗口:拖动背景移动,滚轮缩放,双击关闭,右键菜单有复制、保存、关闭。

## 标注与选区调整(M5a)

选区确定后可以继续编辑:

- 选区调整:拖四边和四角的白色方块缩放,拖选区内部移动;在选区外按下会重新开始选一个新选区
- 一旦画了标注,选区就锁定,不能再移动或缩放(否则标注会和画面错位);撤销全部标注后恢复可调
- 工具条第一行是标注工具,再点一次已选中的工具会取消选中:

| 工具 | 操作 |
|---|---|
| 矩形 | 拖拽,空心框 |
| 箭头 | 从起点拖到终点,带实心箭头 |
| 画笔 | 按住拖动自由绘制 |
| 马赛克 | 拖出矩形,区域像素化 |
| 文字 | 点一下输入,回车确定,`Esc` 放弃这段文字 |

- 第二行是 5 种颜色和 3 档粗细。粗细同时决定文字字号(16 / 22 / 32)和马赛克块大小(8 / 14 / 24)
- 撤销:工具条按钮或 `⌘Z`,逐个撤销
- 标注限制在选区内,复制、保存、贴图、识别输出的都是标注后的图

实现:`Annotation.swift` 里的 `AnnotationRenderer` 同时负责屏幕预览和导出。导出时在原生分辨率的位图上叠加,把视图坐标(点,左上原点)换算成像素。马赛克是把区域缩到每块一个像素再不插值放大。

## 实现要点

- `ScreenGrabber`:先用 `SCScreenshotManager.captureImage` 为每块屏幕抓一帧(按 `backingScaleFactor` 取原生分辨率,不含光标),之后才显示覆盖层,所以截图里不会带上覆盖层本身
- `SelectionOverlay`:每块屏幕一个 `.screenSaver` 层级的无边框窗口;视图是翻转坐标(左上为原点),和 `CGImage` 的坐标一致,裁剪时只需乘以像素/点的比例。多屏时在一块屏幕上开始选择,会清掉其他屏幕上的选区
- 覆盖窗口是 `nonactivatingPanel`(`hidesOnDeactivate = false`)。用普通窗口时,应用还在激活的过程中第一次按下鼠标可能被吞掉,表现为"要拖两次才选得出框"。另外 `mouseDragged` 里加了兜底:如果没收到按下事件,就用第一次拖动的位移反推起点(此修复待实测确认)
- 工具条是挂在覆盖视图上的 SwiftUI 子视图,固定尺寸,`sizingOptions = []`
- OCR:Vision 的 `VNRecognizeTextRequest`,精确模式,开启自动语言检测(中英文混排可用),在后台线程执行
- 复制到剪贴板的是图片,会进入剪贴板历史(图片记录开启时);OCR 的文字结果是文本,同样进入历史
- 需要"屏幕录制"权限。缺少时弹窗引导,不会进入截图界面
- 提示条 `Toast` 放在 `Core/`,供各模块共用;权限提示弹窗也提到了 `PermissionCenter.promptForMissing`,清洁模式和截图共用

## 未实现(M5)

取色器、录屏、长截图、翻译、窗口自动吸附。

## 已知限制

- 第一次授予屏幕录制权限后,系统可能要求重启应用才能生效
- 画了标注后选区锁定
- 标注不能在画完后再移动或修改,只能撤销重画
- 快捷键可在设置窗口自定义,见下面"快捷键自定义"一节
