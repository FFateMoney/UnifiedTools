# 剪贴板历史(Clipboard)

对应里程碑 M3。代码在 `app/UnifiedTools/Modules/Clipboard/`,快捷键注册在 `app/UnifiedTools/Core/HotkeyCenter.swift`。

## 行为

- 默认快捷键 `⌘⇧V`(可在设置里改)呼出浮动面板;菜单栏里也有入口
- 面板:顶部搜索框,下方按时间倒序列出历史;`↑` `↓` 选择,`回车` 粘贴,`Esc` 关闭,点击某条也会粘贴;点面板外自动关闭
- 粘贴:先把该条写回系统剪贴板,再模拟 `⌘V`。该条会被提到最前面。未授权辅助功能时只写回剪贴板,需要手动粘贴
- 记录范围:纯文本、文件路径和图片。同时有文字和图片时(表格、网页)记文字;设置里可以关掉图片记录
- 图片行显示缩略图和像素尺寸,粘贴时按图片写回,图片不参与搜索
- 相同内容只存一份,重复复制只会把它提到最前面
- 菜单栏另有"暂停记录剪贴板"和"清空剪贴板历史…"(清空前会确认)

## 隐私

- 带 `org.nspasteboard.ConcealedType` 或 `org.nspasteboard.TransientType` 标记的复制内容不记录(密码管理器通常会打这两个标记)
- 前台应用在黑名单里时不记录。默认黑名单:钥匙串访问、密码、1Password(两个版本)、Bitwarden。可在设置窗口里增删,填应用的 Bundle ID
- 超过 20 万字符的文本不记录
- 历史存在本机 `~/Library/Application Support/UnifiedTools/clipboard.sqlite`,明文保存,没有加密。图片以 PNG 文件存在同目录的 `images/` 下,文件名是内容哈希;记录被裁剪或清空时对应的图片文件会一并删除

## 实现要点

- `ClipboardMonitor`:每 0.5 秒检查 `NSPasteboard.changeCount`;自己写回剪贴板时同步更新计数,避免把粘贴动作再记一遍
- `ClipboardStore`:直接用系统 SQLite3,没有引入第三方依赖。内容的 SHA-256 作为唯一键,`ON CONFLICT` 时只更新时间;每次写入后按上限裁剪旧记录;搜索用 `LIKE`,对 `%` `_` `\` 做转义
- 按键:文本框会先吃掉 `↑` `↓` 和回车,SwiftUI 的 `onKeyPress` 拿不到,所以在 `ClipPanel.sendEvent` 里于 AppKit 层先截获 `↑`(126)、`↓`(125)、回车(36、小键盘 76)、`Esc`(53),交给 `ClipboardPanelModel`。输入法正在组词(有 marked text)或按着 ⌘⌃⌥ 时不截获,避免打断中文输入
- 面板 `ClipboardPanelController`:`nonactivatingPanel`,不激活本应用,所以原来的应用保持在前台,模拟的 `⌘V` 能粘贴到它。每次打开都创建新视图,搜索词和选中项自动重置。窗口和内容固定尺寸,`sizingOptions = []`(清洁模式踩过布局崩溃的坑)
- `HotkeyCenter`:用 Carbon `RegisterEventHotKey`。注册失败会区分"被其他应用占用"和其他错误,在设置窗口的"快捷键"一栏显示

## 清洁模式快捷键

随 M3 一起加了默认 `⌃⌥⌘K`(可在设置里改)= 黑屏并锁定键盘。它只能开始,不能结束,因为锁定后键盘已失效;结束仍靠长按鼠标左键 3 秒或超时。

## 已知限制

- 快捷键可在设置窗口自定义,见 `hotkeys.md`
- 需要先退出原来的 iCopy 和 iShot,否则快捷键可能冲突
- 不记录富文本格式,文字粘贴出来是纯文本
- 单张图片超过 40MB 不记录

## 手动测试清单

- [ ] 复制几段文字和一个文件,按 `⌘⇧V` 能看到记录,来源应用和时间正确
- [ ] 在文本编辑器里用面板粘贴一条,内容正确且该条移到最前
- [ ] 搜索框输入关键字能过滤;输入 `%` 或 `_` 不会匹配所有记录
- [ ] `↑` `↓` 回车 `Esc` 都正常;点面板外面板消失
- [ ] 重复复制同一段文字,历史里只有一条
- [ ] 暂停记录后复制不入库,恢复后正常
- [ ] 把某个应用的 Bundle ID 加入黑名单,在它里面复制不入库
- [ ] 用密码管理器复制密码不入库
- [ ] 设置窗口"快捷键"一栏显示 `⌘⇧V` 和 `⌃⌥⌘K` 都是正常状态
- [ ] 清空历史后列表为空,`images/` 目录里的图片文件也被删除
- [ ] 用截图的"复制"、或在别处复制一张图片:面板里出现缩略图和像素尺寸,粘贴到别的应用是原图
- [ ] 在设置里关闭"记录图片"后,复制图片不再入库
- [ ] 退出再启动应用,历史还在
